# 🏗️ Sky Stack

Tap to drop each sliding block and build the tallest tower you can. Overhangs get sliced off — line up perfectly to keep your tower wide.

**▶ Play now:** https://dazzar2025.github.io/publicgames3/

- Works on phones, tablets and desktop browsers — no install, no sign-up
- Controls: tap anywhere, or Space / Enter.
- Your best score is saved in your browser

Single self-contained `index.html` — no build step, no dependencies.
